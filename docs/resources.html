02 / SOURCE RESPONSIBILITYBE ORIGINAL AND HONEST

Make reference work.
Keep it legal.

01

Visit the original.

Source links open the actual project. Our previews use authored HTML/CSS and do not claim to render that project's shipped components.

02

Check the license.

Permissive repository code does not automatically license screenshots, premium examples, photographs, third-party fonts or trademarks.

03

Keep the user in mind.

Pick a pattern because it improves a task, communication or feedback. Skip heavy effects if reduced motion or performance constraints demand it.
