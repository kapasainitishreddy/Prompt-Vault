04 / THE WORKFLOWCREATIVE DIRECTION MEETS PRODUCT REALITY

Better outcomes
don't happen by prompt alone.

01Research the real job

Start from audience, context and true product content. Never invent the proof.

02Explore distinct directions

Three genuinely different compositions. Not one template in three colors.

03Build working states

All the way through empty, success, offline and error, with accessible controls.

04Render and inspect

Desktop, mobile, keyboard and reduced motion, using actual observed evidence.

05Critique, then stop

Repair the largest defects. Four rounds maximum to avoid endless token burn.
