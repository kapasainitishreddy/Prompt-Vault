# Website section prompts (32)

All prompts are standalone and can be copied into a coding agent. Fill the six placeholders, or use `scripts/section_prompt.py` to compose prompts from a brief. Each section includes an original art-direction exercise, motion specification, edge-state coverage and a bounded implementation/review loop.
