# Agent craft workflows · 16 original reusable skills

These are **new Prompt-Vault implementations of common design tasks** inspired by four research repositories. They are not copies of the authors' skill files or endorsements by those authors. Do not install all upstream packages; choose the relevant craft task.

- [Motion Judgment Review](motion-judgment.md) — **Interaction** · Decide which interface movements improve orientation, what to delete, and how to tune curves
- [Native Gesture and Motion](expo-motion.md) — **Native app** · Make Expo/React Native motion respond to gesture and navigation without blocking JS
- [Three-Direction Prototype](variant-studio.md) — **Exploration** · Produce three visually and structurally different live candidates rather than three recolors
- [Worst-Case Interface Breaker](stress-test-interface.md) — **QA** · Stress real UI with pathological content and accessibility constraints
- [Dependency and Primitive Selector](component-choice.md) — **Engineering** · Choose the smallest mature accessible UI primitive instead of duplicating fragile behavior
- [Illustrated Interaction System](sketch-language.md) — **Art direction** · Create an original expressive sketch-like system with real task clarity
- [Visual Theme Remix Study](style-remix.md) — **Exploration** · Apply multiple distinct art-direction systems to the same real product content
- [Tactile Metaphor Audit](skeuomorphism-purpose.md) — **Art direction** · Use physical material metaphors only where they help users predict actions
- [Industry and Audience Fit](industry-fit.md) — **Strategy** · Select layout grammar, content and trust evidence for a real product category
- [Design Tokens and Typography](tokens-and-type.md) — **Design system** · Derive color roles and type pairings from brand meaning and real data density
- [UX Pattern Reasoning](ux-pattern-match.md) — **Strategy** · Choose proven interaction patterns based on user task rather than fashion
- [Visual System Regression Review](design-system-review.md) — **QA** · Audit a complete UI for token drift, missing states, broken responsive hierarchy
- [3D and WebGL Viability](webgl-budget.md) — **Advanced visuals** · Decide if a 3D scene materially explains a product before adding a heavy renderer
- [Scroll Narrative With Restraint](scroll-story.md) — **Advanced visuals** · Use GSAP/Motion scroll storytelling without scroll hijack or trapping content
- [Shader and Postprocessing Safety](shader-performance.md) — **Advanced visuals** · Use GPU effects only when a specific visual job survives slow devices
- [2D and Animated Illustration](animated-illustrations.md) — **Advanced visuals** · Create expressive but accessible 2D illustrative cues driven by real interactions
