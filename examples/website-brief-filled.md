# Example brief: Prompt-Vault Design Loops landing page

**Product:** Prompt-Vault Design Loops, free open-source design prompts.
**Audience:** solo makers, freelance designers and developers tired of templated AI-generated sites.
**Goal:** read a track, copy it into a coding assistant, and make a better real interface.
**Primary CTA:** Read the website loop at /prompts/website/LOOP.md on GitHub.
**Secondary CTA:** Read the app loop.
**Real proof:** two separate free prompt tracks; research evidence map; finite offline review manager; MIT license.
**Brand feeling:** editorial, rigorous, optimistic, intentionally uncorporate.
**Avoid:** purple glow and scattered glass cards, fake client testimonials, false "AI trained" claims.
**No externally licensed photography:** use authored CSS or SVG and actual code output.
**Stack:** any, but demo should run as a standalone static HTML file.
**Success:** three-screen responsive layout, working actual links, accessible focus and disclosure of demo limitations.
