# Example app brief: Tally, offline task-capture exercise

**App:** Tally, an illustrative local-only task capture interface.
**Platform:** Browser demo showing mobile-first product UX; not a shipping native app.
**Job:** Capture a quick task, complete it and recover an accidental completion.
**Primary success:** item persists in the UI, action acknowledged and user can undo.
**States:** empty, populated, validation failure, completed, undo, refreshed session.
**Privacy:** data stays inside browser localStorage; no accounts or server.
**Styling:** calm ink, warm white, distinctive left rail and expressive text hierarchy; avoid fake analytics.
**Accessibility:** keyboard action, focus, labels, form error messages and reduced motion.
**Limits:** storage can be cleared; no multi-device sync, notifications, payments or user accounts.
**Evidence:** local browser screenshots + manual keyboard and mobile viewport checks.
